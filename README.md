# Hotel Room Reservation System

A web-based hotel room reservation system built with Java Servlets and JSP.
Data is stored in text files (no database).

## Features
- User management (register, login, search, update, delete)
- Room management (add, view, update, delete rooms)
- Room availability search
- Bookings and cancellations

## Tech Stack
- Java, Servlets, JSP
- HTML/CSS, Bootstrap
- File read/write storage (`.txt`)
- IntelliJ IDEA, Maven, Apache Tomcat
